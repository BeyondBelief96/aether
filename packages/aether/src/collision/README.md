# collision (Phase 5)

Collision geometry: shapes and their support functions, bounding boxes, the broadphase, the narrowphase (primitive tests, SAT, GJK and EPA) and contact manifolds.

The module works on shapes and transforms only and never sees a body. Rigid bodies attach shapes through `Collider` in `bodies/contacts/`.

See [PLAN.md, Phase 5](../../../../docs/PLAN.md#phase-5-collision-detection).
