Aether is a 3D rigid-body physics engine for TypeScript, written from scratch with no dependencies. It never touches the DOM, so the same code runs in the browser, in Node and in a Web Worker.

It's being built in the open, one layer at a time. Math, particles and force generators work today. Rigid bodies, collision detection, contacts and joints are next; the [roadmap](../#roadmap) has the order.

These docs follow the engine. Pages marked **stub** are outlines that fill in as each part of the API settles.
