Aether is a 3D physics engine for TypeScript, written from scratch with no dependencies. It never touches the DOM, so the same code runs in the browser, in Node and in a Web Worker.

It has a math library (vectors, matrices, quaternions), a fixed-timestep loop, particles, force generators (gravity, drag, springs, bungees, buoyancy and attraction) and particle contacts: a ground plane, cables, rods, a contact resolver, and an interface for writing your own contact generators.

Pages marked **stub** are short outlines. The demos' source shows the full API in use.
